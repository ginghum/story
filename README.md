# カス校 — STORY ARCHIVE

カス校メインストーリーのブラウザ向けストーリーモード。PC・スマートフォン横持ちを基本に、プロローグと第1章第1〜6話の全文を収録しています。

タイトル → ストーリー選択 → 第1章 → 各エピソード。クリック・タップ・Space・右矢印で進みます。場所カットイン、立ち絵の表情、挿絵、オート、既読スキップ、ログ、文字速度・サイズ変更、途中保存を搭載しています。BGMと音声は未収録です。

保存はブラウザのlocalStorageを利用します。別端末へは同期されません。

静的サイトのため、HTTPサーバーからそのまま配信できます。GitHub Actionsがmainへの更新でGitHub Pagesへ配置します。

本編原文: ginghum/cursehighschool- の stories.json。原作は変更せず、このゲーム用に台本を分けています。本文の非空行を順序どおり保持し、長い地の文の表示区切りを追加しています。

第6話は原文740行・12シーンを収録。第7話は tools/drafts/ に原文と15シーンの演出計画を保存しています（プレイ対象には未追加）。
